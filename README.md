# Tattoo Stories

Одностраничный сайт тату-мастера Ани на React, TypeScript, Vite и SCSS Modules.

Проект использует локализацию RU/EN, светлую и тёмную темы, адаптивную mobile-first вёрстку и анимации, учитывающие `prefers-reduced-motion`.

---

## Структура страницы

Файл: `src/app/App.tsx`

Текущий порядок секций:

1. `Header`
2. `Hero`
3. `Intro`
4. `Stories`
5. `Foundation`
6. `Sketch`

---

## Application entry point

Файл: `src/main.tsx`

Файл является точкой входа React-приложения.

Приложение запускается через `createRoot` и рендерится в элемент `#root`.

`StrictMode` используется для дополнительных проверок React в development-режиме.

`ThemeProvider` предоставляет состояние темы всему приложению.

`LanguageProvider` предоставляет текущий язык и словарь локализации.

Глобальные стили подключаются через `src/styles/main.scss`.

# Локализация

## LanguageContext

Файл: `src/context/LanguageContext.tsx`

Контекст хранит текущий язык приложения и предоставляет соответствующий словарь переводов.

Поддерживаемые языки:

- `ru`
- `en`

При инициализации язык определяется в следующем порядке:

1. сохранённое значение из `localStorage`;
2. язык браузера;
3. fallback.

Текущий язык сохраняется в `localStorage`, а атрибут `lang` у `<html>` синхронизируется с выбранной локализацией.

## useLanguage

Файл: `src/hooks/useLanguage.ts`

Хук предоставляет доступ к `LanguageContext`.

Если `useLanguage` вызывается вне `LanguageProvider`, выбрасывается ошибка. Это защищает компоненты от использования локализации без подключённого провайдера.

## Localization

Файлы:

- `src/locales/ru.ts`
- `src/locales/en.ts`

Файлы содержат словари интерфейса.

Структура словаря соответствует типу `Translation` и разделена по компонентам и секциям страницы:

- `common` — общие элементы интерфейса;
- `hero` — первый экран;
- `intro` — знакомство;
- `stories` — карусель историй;
- `foundation` — секция «Основа»;
- `sketch` — секция «Эскиз»;
- `navigation` — названия пунктов навигации.

Структура ключей должна совпадать во всех локализациях проекта.

## Типы локализации

Файл: `src/locales/types.ts`

Тип `Language` ограничивает поддерживаемые языки значениями `ru` и `en`.

Тип `Translation` задаёт единую структуру словарей локализации. Русская и английская версии должны содержать одинаковый набор ключей.

Для темы поддерживаются только светлый и тёмный режимы.

# Тема

## ThemeContext

Файл: `src/context/ThemeContext.tsx`

Контекст управляет светлой и тёмной темами приложения.

Поддерживаемые значения:

- `light`
- `dark`

По умолчанию используется светлая тема.

Выбранная тема сохраняется в `localStorage`.

Атрибут `data-theme` у `<html>` синхронизируется с выбранным режимом.

`resolvedTheme` сохраняется в контексте для совместимости и в текущей реализации совпадает со значением `theme`.

Системная тема не используется.

## useTheme

Файл: `src/hooks/useTheme.ts`

Хук предоставляет доступ к `ThemeContext`.

Если `useTheme` вызывается вне `ThemeProvider`, выбрасывается ошибка. Это защищает компоненты от использования контекста темы без подключённого провайдера.

## ThemeToggle

Файл: `src/components/ui/ThemeToggle/ThemeToggle.tsx`

Переключатель позволяет выбирать светлую или тёмную тему.

Активная тема отражается через `aria-pressed` и `data-active`.

## TypedText

Файл: `src/components/ui/TypedText/TypedText.tsx`

Компонент печатает текст посимвольно.

Поддерживаемые состояния:

- `waiting`;
- `active`;
- `complete`.

Текст разбивается на слова, а символы каждого слова оборачиваются отдельно. Благодаря этому браузер не переносит слово посередине во время анимации.

Анимация запускается только когда компонент находится в viewport.

Для анимации используется `requestAnimationFrame`.

Скорость хранится через `speedRef`, поэтому её можно менять во время уже запущенной печати без перезапуска эффекта. Это используется в Foundation для ускорения текста при достижении его шариком.

При `prefers-reduced-motion: reduce` текст показывается сразу.

## TypedText styles

Файл: `src/components/ui/TypedText/TypedText.module.scss`

Каждый символ плавно появляется через изменение `opacity` и `filter`.

Слова обёрнуты в `inline-block`, чтобы не допускать переноса посередине слова.

При `prefers-reduced-motion: reduce` символы отображаются сразу без transition.

# Hooks

## useInView

Файл: `src/hooks/useInView.ts`

Хук определяет присутствие элемента в viewport через `IntersectionObserver`.

Порог видимости передаётся аргументом.

После появления элемента `isInView` становится `true`.

Состояние сбрасывается только после полного выхода элемента из viewport, поэтому анимация может повторно запускаться при возвращении пользователя к секции.

При `prefers-reduced-motion: reduce` элемент сразу считается видимым.

## useLockBodyScroll

Файл: `src/hooks/useLockBodyScroll.ts`

Хук блокирует прокрутку `body` через `overflow: hidden`.

Перед изменением сохраняется исходное значение `overflow`, которое восстанавливается при снятии блокировки или размонтировании.

Используется мобильным меню.

## useScrollProgress

Файл: `src/hooks/useScrollProgress.ts`

Хук вычисляет прогресс прохождения элемента через viewport в диапазоне от `0` до `1`.

Полученное значение записывается в CSS-переменную `--scroll-progress`.

Также хук может передавать текущее значение через callback.

В Foundation callback используется для определения момента, когда движущийся шарик достигает конкретного текстового блока.

Расчёт начинается примерно при входе элемента на уровне 80% высоты viewport и заканчивается около 20%.

Дополнительно учитывается конец документа, чтобы прогресс мог завершиться даже для элементов около нижней границы страницы.

Обновления во время scroll и resize объединяются через `requestAnimationFrame`.

При `prefers-reduced-motion: reduce` прогресс сразу устанавливается в `1`.

Все event listeners и запланированные animation frame очищаются при размонтировании.

## useTypingSequence

Файл: `src/hooks/useTypingSequence.ts`

Хук управляет последовательным запуском анимации нескольких текстовых блоков.

Состояния элемента:

- `waiting` — ожидает своей очереди;
- `active` — сейчас анимируется;
- `complete` — уже завершён.

`activeIndex` хранит индекс текущего активного элемента.

`completeStep(index)` переводит очередь к следующему элементу только в том случае, если завершился именно текущий активный элемент.

`getState(index)` возвращает состояние конкретного элемента относительно текущей позиции очереди.

Если `isActive` становится `false`, последовательность сбрасывается к первому элементу.

# Hero

## Hero

Файл: `src/sections/Hero/Hero.tsx`

Hero использует отдельное изображение `hero-reference.jpg`, размещённое поверх фонового цвета секции.

Изображение считается декоративным, поэтому имеет пустой `alt` и скрыто от accessibility-дерева через `aria-hidden` у контейнера.

Для Hero используется `fetchPriority="high"`, поскольку изображение находится на первом экране и должно загружаться приоритетно.

Тексты Hero берутся из текущей локализации через `useLanguage`.

`logoPlaceholder` временно отображает `TS` и предназначен для последующей замены на настоящий векторный логотип.

## Hero styles

Файл: `src/sections/Hero/Hero.module.scss`

Hero занимает минимум всю высоту viewport и использует `--hero-background` как основной фон.

Фотография размещается отдельным абсолютным слоем поверх фона, а не используется как `background-image`. Благодаря этому фон страницы остаётся самостоятельной частью композиции, а изображение можно независимо масштабировать и заменять.

Поверх изображения используется лёгкий градиентный overlay для сохранения читаемости светлого текста.

Основной контент Hero находится выше изображения по `z-index` и центрируется по горизонтали и вертикали.

`logoPlaceholder` — временная заглушка для будущего векторного логотипа.

Размеры заголовка и подписи адаптивны через функцию `fluid`.

На tablet и laptop увеличиваются размеры изображения, отступы и максимальная ширина контента.

# Intro

## Intro

Файл: `src/sections/Intro/Intro.tsx`

Секция Intro использует `useInView` для запуска анимации, когда секция появляется в viewport.

Три текстовых блока выводятся последовательно через `useTypingSequence`:

1. основной lead;
2. основной текст;
3. заключительная note.

Каждый блок использует `TypedText` со своими скоростью и задержками.

После завершения одного блока вызывается `completeStep`, который разрешает запуск следующего.

Порог появления секции для запуска анимации — `0.15`.

## Intro styles

Файл: `src/sections/Intro/Intro.module.scss`

Секция Intro центрирует заголовок и весь текстовый контент.

Используются общие CSS-переменные темы: `--color-background`, `--color-text`, `--color-text-muted`.

Заголовок использует декоративный шрифт проекта и адаптивный размер через `fluid`.

Текстовая часть ограничена по ширине, чтобы длинные абзацы оставались читаемыми на desktop.

У `.note` используется короткая горизонтальная линия через `::before` как декоративный разделитель.

На tablet увеличиваются вертикальные отступы, а начиная с laptop секция занимает минимум 85% высоты viewport и выравнивается по вертикальному центру.

# Stories

## Stories data

Файл: `src/data/stories.ts`

Файл содержит данные карточек портфолио.

Каждая история включает `id`, номер работы, импорт изображения, ключ категории и ключ подписи.

Текстовые значения хранятся не в данных карточек, а в словарях локализации.

Изображения импортируются как Vite assets.

## Stories

Файл: `src/sections/Stories/Stories.tsx`

Компонент управляет горизонтальной каруселью работ.

`trackRef` предоставляет доступ к scroll-контейнеру.

Состояния `canScrollPrevious` и `canScrollNext` определяют доступность кнопок навигации на основе текущей позиции горизонтального скролла.

`scrollToCard` плавно прокручивает карусель до выбранной карточки.

Активная карточка определяется через `IntersectionObserver`. Наблюдатель работает относительно контейнера карусели и выбирает наиболее видимую карточку.

Индекс карточки хранится в атрибуте `data-index` и используется для обновления счётчика.

Состояние доступности кнопок обновляется при прокрутке карусели и изменении размера окна.

При размонтировании компонента наблюдатель и обработчики событий удаляются.

## Stories styles

Файл: `src/sections/Stories/Stories.module.scss`

Секция Stories представляет собой горизонтальную карусель работ со scroll snap.

`.track` поддерживает горизонтальный скролл, плавную прокрутку, `scroll-snap`, touch-прокрутку на мобильных устройствах и скрытые системные полосы прокрутки.

На mobile отображается примерно одна карточка за экран с видимым краем следующей.

На tablet ширина карточек рассчитывается примерно для двух элементов в ряд, а на laptop — для трёх.

На больших экранах горизонтальные отступы карусели учитывают максимальную ширину общего контейнера сайта.

Навигационные кнопки имеют состояния hover, focus и disabled.

На устройствах с поддержкой hover изображение карточки слегка увеличивается при наведении.

## StoryCard

Файл: `src/sections/Stories/StoryCard.tsx`

Компонент отображает одну карточку работы в секции Stories.

Данные карточки передаются через объект `Story`.

Категория и подпись изображения берутся из текущей локализации по ключам `categoryKey` и `captionKey`.

Изображения загружаются лениво через `loading="lazy"` и декодируются асинхронно через `decoding="async"`.

Номер работы является декоративным и скрыт от accessibility-дерева через `aria-hidden`.

# Foundation

## Foundation

Файл: `src/sections/Foundation/Foundation.tsx`

Компонент отвечает за секцию «Основа».

Заголовок и текст секции берутся из текущей локализации через `useLanguage`.

Основной контент передаётся в `FoundationTimeline`, который отвечает за анимацию линии, движение шарика и последовательное появление текста.

Секция связана с навигацией через якорь `#foundation`.

## Foundation styles

Файл: `src/sections/Foundation/Foundation.module.scss`

Секция Foundation использует собственные CSS-переменные темы `--foundation-background` и `--foundation-text`.

Контент секции выровнен по центру, а заголовок использует декоративный шрифт проекта и адаптивный размер через `fluid`.

Вертикальные отступы и расстояние между заголовком и содержимым увеличиваются на tablet и laptop breakpoint.

Начиная с laptop секция занимает минимум высоту viewport и выравнивает содержимое по вертикальному центру.

## FoundationTimeline

Файл: `src/sections/Foundation/FoundationTimeline.tsx`

Компонент синхронизирует движение шарика, прогресс линии и последовательное появление текста в секции Foundation.

Используются две скорости печати:

- `NORMAL_SPEED = 30` — обычное появление текста;
- `SCROLL_SPEED = 16` — ускоренная печать, когда шарик уже достиг соответствующего текстового блока.

Положение шарика отслеживается через `useScrollProgress`.

Для каждого текстового блока сохраняется DOM-ссылка, поэтому момент активации определяется по реальному положению шарика относительно текста, а не по фиксированным процентам секции.

У текста два способа разблокировки:

1. `scrollUnlockedIndex` — текст разрешается, когда до него физически дошёл шарик;
2. `autoUnlockedIndex` — текст постепенно разрешается по времени, если пользователь находится в секции и не прокручивает страницу.

Фактически доступный индекс определяется как максимальное значение из этих двух состояний.

Тексты всё равно появляются строго последовательно через `useTypingSequence`: следующий абзац не начинает печататься, пока предыдущий не завершён.

При выходе секции из viewport состояние разблокировки сбрасывается, поэтому при повторном входе анимация может запускаться заново.

## FoundationTimeline styles

Файл: `src/sections/Foundation/FoundationTimeline.module.scss`

Секция использует CSS-переменную `--scroll-progress` со значением от `0` до `1`.

Вертикальная линия проходит через весь блок Foundation. Её фоновая часть задаётся через `.track`, а заполненная часть масштабируется по вертикали через `.trackProgress`.

Положение шарика `.dot` синхронизировано со значением `--scroll-progress`, поэтому он движется вдоль линии при прокрутке страницы.

Текстовые блоки располагаются поверх линии и используют фон `--foundation-background`. Благодаря этому линия визуально видна только в промежутках между абзацами.

`.spacer` задаёт пространство между текстовыми блоками, в котором видны движение шарика и заполнение линии.

На tablet и laptop увеличиваются вертикальные интервалы, а максимальная ширина текста адаптируется под больший экран.

# Sketch

## Sketch

Файл: `src/sections/Sketch/Sketch.tsx`

Компонент использует последовательность состояний:

- `waiting` — секция ещё не запущена;
- `lead` — печатается первый текст;
- `ink` — рисуется декоративная SVG-линия;
- `text` — печатается второй текст;
- `complete` — вся последовательность завершена.

Анимация запускается при появлении секции во viewport через `useInView` с порогом `0.2`.

После завершения первого `TypedText` начинается стадия `ink`.

Обычная длительность стадии рисования линии — `1650ms`. После неё запускается второй текст.

При `prefers-reduced-motion: reduce` ожидание анимации линии пропускается, и компонент сразу переходит к стадии `text`.

Если секция полностью выходит из области видимости, состояние сбрасывается в `waiting`, поэтому последовательность может запуститься снова при повторном появлении.

## Sketch styles

Файл: `src/sections/Sketch/Sketch.module.scss`

Секция Sketch центрирует заголовок и основной текстовый контент.

Между двумя текстовыми блоками расположен SVG-элемент `.ink`, состоящий из линии `.inkPath` и точки `.inkDot`.

Анимация управляется через атрибут `data-stage` у секции:

- `ink` — линия рисуется, после чего появляется точка;
- `text` — линия и точка остаются полностью видимыми во время появления второго текста;
- `complete` — финальное состояние сохраняет нарисованную линию и точку.

Линия рисуется через изменение `stroke-dashoffset`.

Для пользователей с `prefers-reduced-motion: reduce` анимации отключаются, а линия и точка сразу отображаются в конечном состоянии.

На tablet и laptop увеличиваются размеры декоративной линии и интервалы между элементами. Начиная с laptop секция занимает минимум полную высоту viewport.

# SCSS architecture

## Main styles entry point

Файл: `src/styles/main.scss`

Файл является основной точкой подключения глобальных стилей проекта.

Он подключает локальные шрифты, светлую и тёмную темы, CSS reset, базовую типографику и глобальные стили документа.

## Breakpoints

Файл: `src/styles/abstracts/_breakpoints.scss`

Проект использует mobile-first подход с breakpoint через `min-width`.

Доступные значения:

- `mobile` — от `480px`;
- `tablet` — от `768px`;
- `laptop` — от `1024px`;
- `desktop` — от `1280px`;
- `wide` — от `1600px`.

Для каждого breakpoint предусмотрен одноимённый Sass mixin.

Пример:

```scss
@include bp.tablet {
  ...
}
```

## Sass functions

Файл: `src/styles/abstracts/_functions.scss`

Функция `rem($pixels, $base: 16)` переводит значение из пикселей в `rem`.

Пример: `rem(16)` → `1rem`.

Функция `fluid($min-size, $max-size, $min-width: 375, $max-width: 1440)` создаёт адаптивное значение через CSS `clamp`.

Размер плавно меняется между минимальным и максимальным значением в зависимости от ширины viewport.

Пример: `fluid(42, 120)` даёт размер около `42px` на маленьком экране и постепенно увеличивает его до `120px` на больших экранах.

## Sass mixins

Файл: `src/styles/abstracts/_mixins.scss`

Файл содержит общие Sass mixin для повторно используемых стилей.

Доступные mixin:

- `container` — ограничивает ширину контента и задаёт адаптивные горизонтальные отступы;
- `flex-center` — центрирует содержимое через flex;
- `absolute-fill` — растягивает абсолютно позиционированный элемент на всю область родителя;
- `image-cover` — растягивает изображение по контейнеру через `object-fit: cover`;
- `reset-button` — сбрасывает стандартные стили кнопки;
- `visually-hidden` — визуально скрывает элемент, сохраняя его доступным для screen reader;
- `text-truncate` — обрезает однострочный текст через ellipsis;
- `focus-visible` — добавляет видимый outline при клавиатурном фокусе;
- `hover` — включает hover-стили только на устройствах с полноценной поддержкой hover;
- `reduced-motion` — позволяет отключать или упрощать анимации для пользователей с `prefers-reduced-motion: reduce`.

Mixin `container` использует mobile-first отступы и увеличивает их на tablet и desktop breakpoint.

## Sass variables

Файл: `src/styles/abstracts/_variables.scss`

Файл содержит основные дизайн-токены проекта: цвета, шрифты, веса шрифтов, размеры контейнера, отступы, радиусы, переходы и уровни `z-index`.

Основной декоративный шрифт — `UrbanSlavic`, основной текстовый — `Montserrat`.

Максимальная ширина контейнера — `1440px`.

Горизонтальные отступы страницы:

- mobile — `28px`;
- tablet — `32px`;
- desktop — `64px`.

Mobile-отступ ранее составлял `20px` и был увеличен до `28px`, чтобы дать контенту больше воздуха по краям.

## Fonts

Файл: `src/styles/base/_fonts.scss`

Локальные шрифты подключаются через `@font-face` в формате WOFF2.

Montserrat используется как основной текстовый шрифт и содержит веса от `100` до `900` в обычном и italic начертании.

UrbanSlavic используется как декоративный display-шрифт и подключён в начертании `400 normal`.

Для всех шрифтов используется `font-display: swap`, чтобы текст оставался видимым во время загрузки локальных файлов шрифта.

## Themes

Файл: `src/styles/base/_themes.scss`

Проект поддерживает две темы: светлую и тёмную.

Светлая тема является базовой и задаётся через `:root` и `[data-theme='light']`.

Тёмная тема активируется через `[data-theme='dark']`.

Обе темы используют одинаковый набор CSS-переменных для основного фона и текста, границ, Header, элементов управления, Hero и Foundation.

Компоненты используют CSS-переменные вместо жёстко заданных цветов, поэтому переключение темы не требует изменения стилей отдельных компонентов.

Свойство `color-scheme` сообщает браузеру текущую тему и позволяет системным элементам интерфейса адаптироваться к светлому или тёмному режиму.

## CSS reset

Файл: `src/styles/base/_reset.scss`

Файл сбрасывает стандартные браузерные стили и задаёт единое базовое поведение HTML-элементов.

Основные правила:

- для всех элементов используется `box-sizing: border-box`;
- стандартные margin и padding документа сбрасываются;
- списки отображаются без стандартных маркеров;
- ссылки наследуют цвет и не имеют стандартного подчёркивания;
- элементы форм наследуют шрифт и цвет;
- изображения, SVG, видео и canvas ограничиваются шириной контейнера;
- textarea разрешено изменять только по вертикали;
- таблицы используют объединённые границы;
- элементы с атрибутом `hidden` полностью скрываются.

Плавная прокрутка по умолчанию задаётся через `scroll-behavior: smooth` и отключается глобальными стилями при `prefers-reduced-motion: reduce`.

## Typography

Файл: `src/styles/base/_typography.scss`

Файл задаёт базовую типографику проекта.

Основной текст использует Montserrat, а заголовки `h1–h6` — декоративный UrbanSlavic.

Размеры заголовков и абзацев адаптивно изменяются через функцию `fluid`.

Для заголовков используется `text-wrap: balance`, а для абзацев — `text-wrap: pretty`.

Длинные слова и ссылки могут переноситься через `overflow-wrap: break-word`, чтобы контент не ломал мобильную вёрстку.

Для `strong` и `b` используется вес `600`.

## Global styles

Файл: `src/styles/base/_global.scss`

Глобальные стили задают базовые правила для документа и общих HTML-элементов.

Минимальная ширина страницы — `320px`.

Для `html` используется `scroll-padding-top: 80px`, чтобы переходы по якорям учитывали фиксированный Header.

`body` и `#root` занимают минимум полную высоту viewport.

Для интерактивных элементов применяется общий `focus-visible` стиль.

Элементы форм растягиваются на всю доступную ширину, а disabled-состояние уменьшает прозрачность и показывает недоступный курсор.

При `prefers-reduced-motion: reduce` плавная прокрутка отключается, а длительность переходов и анимаций практически обнуляется.

# Fitting

## Fitting

Файл: `src/sections/Fitting/Fitting.tsx`

Секция отображает этап примерки татуировки на тело.

Контент выводится по центру и состоит из:

- заголовка «Примерка»;
- крупной фразы «Как с одеждой.»;
- lead-текста «Только серьёзнее.»;
- декоративной анимации формы;
- основного объясняющего текста;
- финального абзаца.

Текстовые блоки используют `TypedText` и появляются строго последовательно через `useTypingSequence`.

Порядок анимации:

1. печатается lead;
2. после его завершения разрешается основной текст;
3. после завершения основного текста печатается финальный абзац.

Анимация запускается через `useInView`, когда секция появляется во viewport, и сбрасывается после выхода секции из области видимости.

## Fitting visual

Файл: `src/sections/Fitting/Fitting.module.scss`

Между lead и основным текстом находится декоративный элемент `.fitVisual`.

Он состоит из трёх органических контуров:

- `.shapeOuter`;
- `.shapeMiddle`;
- `.shapeInner`.

При появлении секции контуры имеют разные размеры, повороты и масштаб, после чего плавно сходятся к общей форме.

Анимация символизирует подгонку эскиза под тело и идею «примерки».

Анимация реализована только через CSS и не требует дополнительной JavaScript-логики.

При `prefers-reduced-motion: reduce` движение отключается, а формы сразу отображаются в конечном состоянии.
